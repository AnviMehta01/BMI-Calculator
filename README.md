# BMI Calculator

An Android BMI Calculator application built using Kotlin and Jetpack Compose.

## Features
- Calculate Body Mass Index (BMI)
- Categorize BMI as Underweight, Normal, Overweight, or Obese
- Simple and user-friendly interface
- Real-time BMI calculation

## Technologies Used
- Kotlin
- Jetpack Compose
- Android Studio

## How to Run
1. Clone the repository
2. Open the project in Android Studio
3. Build and run the application on an emulator or Android device
